# SECFetcher v1.3.0

SECFetcher is a lightweight browser extension for fast SEC EDGAR filing lookup by ticker.

This release expands the filing categories available from the popup and reorganizes the controls into grouped sections for quicker scanning.

## What's New

- Added grouped filing controls for core filings, offerings and registration, ownership and funds, and foreign issuers.
- Added S-1 and S-3 registration statement lookup.
- Added 424B prospectus and FWP free writing prospectus lookup.
- Added SC 13D and SC 13G beneficial ownership lookup.
- Added 13F-HR institutional holdings lookup.
- Added 20-F and 6-K foreign issuer filing lookup.
- Included amended forms for the new categories where applicable.

## Core Features

- Search ticker symbols against official SEC company data.
- Fetch recent 10-K, 10-Q, 8-K, DEF 14A, Form 3, Form 4, Form 5, S-1, S-3, 424B, FWP, SC 13D, SC 13G, 13F-HR, 20-F, and 6-K filings.
- Open filings directly on sec.gov.
- Download original SEC filing documents.
- Stores only the latest visible popup results locally in the browser.
- No analytics, no tracking, no account, no required payment, and no remote telemetry.

## Install From Release

Chromium browsers:

1. Download `secfetcher-edge-v1.3.zip`.
2. Unzip it.
3. Open your browser extensions page.
4. Enable developer mode.
5. Choose `Load unpacked`.
6. Select the unzipped folder.

Firefox:

1. Use the signed Firefox Add-ons listing when it is available.
2. For temporary testing, upload or load the Firefox package through Firefox's add-on tooling.
