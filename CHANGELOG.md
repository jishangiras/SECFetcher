# Changelog

## 1.2.0 - 2026-05-15

- Added an optional Stripe donation link in the popup footer.
- Updated release and store documentation to clarify donations are optional and do not unlock features.
- Removed stale placeholder Firefox metadata from the base manifest; Firefox-specific metadata is generated in the Firefox package.

## 1.1.0 - 2026-05-15

- Added insider filings lookup for SEC Forms 3, 4, and 5.
- Updated store packages and screenshots for insider filings support.

- Initial public release.
- Search tickers against SEC company data.
- Fetch 10-K, 10-Q, 8-K, and DEF 14A filings.
- Open filings on sec.gov.
- Download original SEC filing documents.
- Clear ticker and results from the input control.
- Sticky footer in popup.
- Local-only result persistence.
